MacOS 清除 DNS 缓存

下面的指令适用于 MacOS 10.15 到 14（15及以上我没有测试过）

sudo killall -HUP mDNSResponder; sudo dscacheutil -flushcache

因为调用了 sudo ，而且 Mac 默认是没有 root 的，所以需要输入你的登陆密码。

其余 MacOS 版本清除 DNS 缓存的方法可参考 https://sysin.org/blog/how-to-flush-dns-cache/

如果是为了清除 DNS 污染，那么还需要注意一下你的路由器有没有缓存功能（有的话清除或者重启一下）。
