Rime 输入法使用中文+全角&英文+半角

找到你使用的输入方案的自定义文件（我的是 luna_pinyin_simp.custom.yaml），我这里是这样的。

patch:
  switches:
    - name: ascii_mode
      reset: 0
      states: [ "中文", "西文" ]
    - name: full_shape # 全角/半角符号开关
      reset: 0 # ‼️如果没有这一行，那么在这里加上这一行（这里表示默认值）‼️
      states: [ "半角", "全角" ]
    - name: show_emoji # Emoji 开关
      reset: 1
      states: [ "🈚️️\uFE0E", "🈶️️\uFE0F" ]
    - name: zh_simp
      reset: 1
      states: [ "漢字", "汉字" ]
    - options: [ "utf8", "gbk", "gb2312" ]
      reset: 0
      states:
        - UTF-8
        - GBK
        - GB2312

...

这样你在中文模式下按 Ctrl + ` ，切换成全角，就可以做到中文用全角符号，英文用半角符号了。
