Sublime Text 3 增加 GBK编码 支持

Sublime 本身是不支持 GBK编码 的，但我们可以安装插件。

首先需要下载 Package Control ，这个自行 Google 即可。

打开 Sublime 按下 command+shift+P ，在框里面搜索 Package Control: Install Package

选择后，我们就打开了一个插件包管理器。

在里面搜索并下载 converToUTF8 和 Codecs33 （MacOS 和 Linux 需要后者，并重启 Sublime）
