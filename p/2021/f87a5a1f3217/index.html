ubuntu 卸载fcitx输入法

我又来水文章了

打开终端

输入

sudo apt-get remove fcitx
sudo apt-get remove fcitx-module*
sudo apt-get remove fcitx-frontend*
sudo apt-get purge fcitx*

如果您原来使用的就是fcitx输入法，那再输入一句

sudo reboot

重启以后默认就是ibus输入法啦！

ibus大法好！
