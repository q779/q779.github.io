ubuntu GIMP 字体显示异常 解决方法

今天用GIMP的时候发现字体出了问题

主要的问题是Fontconfig warning: FcPattern object width does not accept value [75 100)

找到了一个解决方法，在终端输入以下内容

sudo rm -rf ~/.cache/fontconfig
