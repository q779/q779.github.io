JavaScript 自动点击网页上的按钮

起因：ty巨佬的 nywOJ 作为著名的点兔子网站，编不下去了

做法很简单，只需要按下 F12 ，打开 console ，输入下面的代码

setInterval(function(){document.getElementById("单击按钮的Id").click();},1000);

上面的代码会每隔一秒点击一下按钮的 id

但是我们发现，ty 巨佬没写 id ，只有个 class ，怎么办捏？

如下

setInterval(function(){document.getElementsByClassName("单机按钮的class")[0].click();},1000);

setInterval是一个实现定时调用的函数，可按照指定的周期（以毫秒计）来调用函数或计算表达式。

setInterval方法会不停地调用函数，直到 clearInterval被调用或窗口被关闭。

如果你把 \(1000\) 改成 \(1\)​ 那就每毫秒都会点一次，不过好像 ty 的 oj 不给我一秒点超过十几次（
