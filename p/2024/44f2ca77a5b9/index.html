洛谷P3353 在你窗外闪耀的星星 题解

题目链接：P3353 在你窗外闪耀的星星

题意：

天空可以理解为一条数轴，在这条数轴上分布着许多颗星星，对于每颗星星都有它的位置 \(X_i\) 和自身的亮度 \(B_i\)。一个位置可能有多颗星星。而窗户所能看到的范围是一个给出的参数 \(W\)​，我们看到的星星也包括窗户边缘的星星。现在，要你求出调整窗户位置后能看到星星的亮度之和最大值。

输入格式：

一行 \(N,W\)，分别代表星星的数量和窗户的宽度。

余下 \(N\) 行，输入 \(X_i\) 和 \(B_i\)，代表星星的坐标和亮度。

输出格式：

一个数字，代表能看到星星的最大亮度和。

数据范围：

对于 \(100\%\) 的数据，\(1 \leq N\leq 10 ^ 5\)，\(0 \leq W\leq 10 ^ 5\)，\(1 \leq X_i\leq 10 ^ 5\)，\(1\leq B_i\leq 100\)。

除 \(W=0\) 的情况外，\(W\) 均为 \(\geq 3\) 的奇数。

把所有的点按 \(x\) 排序，然后维护一个指针 \(p\) 跟着 \(i\) 跑就完事了

时间复杂度 \(\mathcal{O}(n \log n)\) ，空间复杂度 \(\mathcal{O}(n)\) ，题目里其他的限制意义不明。

代码：

#include <bits/stdc++.h>
using namespace std;
// #define int long long
// #define INF 0x3f3f3f3f3f3f3f3f
void up(int &x,int y) { x < y ? x = y : 0; }
void down(int &x,int y) { x > y ? x = y : 0; }
#define N ((int)(1e5 + 15))

int res, p = 1, sum[N];
struct node { int x, v; } a[N];
signed main()
{
    ios::sync_with_stdio(0);
    cin.tie(0);cout.tie(0);
    // freopen("check.in","r",stdin);
    // freopen("check.out","w",stdout);
    int n, m; cin >> n >> m;
    for(int i = 1; i <= n; i++) cin >> a[i].x >> a[i].v;
    sort(a + 1, a + 1 + n, [](node a, node b) { return a.x < b.x; });
    for(int i = 1; i <= n; i++) sum[i] = sum[i - 1] + a[i].v;
    for(int i = 1; i <= n; i++) {
        while(p <= n && a[i].x - a[p].x >= m) ++p;
        up(res, sum[i] - sum[p - 1]);
    }
    cout << res << '\n';
    return 0;
}
