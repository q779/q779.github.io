为 Hexo 博客添加 Umami 网站访问量统计工具

Umami 是个十分不错的网站访问量统计的开源工具，本文将介绍如何通过 Vercel 部署自己的工具。

不过因为本文利用 Vercel 直接提供统计服务，所以来自中国大陆等地区的直连访客很可能无法统计到。

本人水平有限暂时没有什么好主意，况且本站暂时没有为普通大陆用户提供稳定服务的计划，暂且搁置。

不过首先，你需要有一个 Github 账号，和一个 Vercel 的账号，没有的话就不用看本文了。

一、建立数据库

这里简单起见，就不找别的提供商了，直接用 Vercel 上的第三方数据库服务。

打开 Vercel ，在侧边栏找到这个 Storage 。

因为 umami 官方文档要求使用 PostgreSQL，所以这里我们直接选择 Neon 作为数据库。

点进这个域名以后，会让你登录账号。默认的账号是 admin ，密码是 umami ，记得改密码。

接着就是小学生都会的内容了，把你的网址加进去，如下图所示。

然后点击右边的编辑，找到类似下面这样的 script 段落，复制一下。

接下来到你的博客里，在页面底部（即 </body> 的前面）加上这段 <script> 即可。

像我这里 Butterfly 主题，可以直接在配置文件里直接注入，如下

inject:
  head:
    # - <link rel="stylesheet" href="/xxx.css">
  bottom:
    - <script src="/qwq/cdn/live2d-widget/dist/autoload.js"></script>
    # 在这里添加刚才的 <script>

值得注意的是，直接这么注入，对于普通大陆用户来说，很可能会影响网页的正常加载。

因此我们需要采用异步加载，这样在页面完全加载完成时，再尝试加载这个就不会影响正常浏览网页了。

怎么写呢？不好意思，因为我不会 javascript，所以我让 ChatGPT 帮我写的，如下（记得改成自己的设置）

<script>(()=>{const load=()=>{const s=document.createElement('script');s.src='https://abcd.vercel.app/script.js';s.async=true;s.dataset.websiteId='abcd-abcd';document.head.appendChild(s)};if(document.readyState==='complete')load();else window.addEventListener('load',load,{once:true})})();</script>

如果你会 javascript 你可以自己写一个，反正我这里的代码用着貌似没有问题，我就暂时不管了。
