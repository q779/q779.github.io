Python语法 print 函数

print() 是用于打印输出的常见函数，在 Python3.3 版增加了 flush 关键字参数。

一、基础语法

print(*objects, sep=' ', end='\n', file=sys.stdout, flush=False)

其中

  • objects 表示可以一次输出多个对象。输出多个对象时，需要用 , 分隔。
  • sep 用来设定间隔多个对象的分隔符，默认值是一个空格。
  • end 用来设定以什么结尾。默认值是换行符 \n 。
  • file 要写入的文件对象。
  • flush 输出是否被缓存通常决定于 file，但如果 flush 关键字参数为 True，流会被强制刷新。

print 函数无返回值。

例子

代码1

print(111, "abcd")

a = [1, 2, 'a']; print(a)

b = (1, 2, 'a'); print(b)

c = {'a' : 1, 'b' : 2}; print(c)

输出1

111 abcd
[1, 2, 'a']
(1, 2, 'a')
{'a': 1, 'b': 2}

代码2

for i in range(20):
    print(".",end = '',flush = True)

二、格式化输出

代码1

str = "the length of %s is %d" % ("abcd", len("abcd"))
print(str)

输出1

the length of abcd is 4

当然你也可以写成下面这样的 C 风格

代码2

print("the length of %s is %d" % ("abcd", len("abcd")))

输出2（和输出1是一样的）

the length of abcd is 4

3. 各种输出例子

代码：

a = 63; print("#1")
print("hex: %x, dec: %d, oct: %o" % (a, a, a))

b = 3.1415926; print("#2")
print("%.3f" % b)
print("b = %.3lf" % b) # 兼容 C 风格写法
print("%.*f" % (4, b)) # 位数写在后面
print("%10.3f" % b) # 字段至少宽10，小数点后显示3位
print("%-10.3f" % b) # 左对齐
print("%010.3f" % b) # 前导零
print("%+f" % b)

c = 123456; d = 123; print("#3")
print("%6dqwq%6d" % (c, d)) # 字段宽度不小于 6 则照常输出，否则补空格

e = 1.234; f = 1.2; g = 1.3; print("#4")
print("%5.2fqwq%5.2fqwq%5.2f" % (e, f, g)) # 字段宽度包含小数点和小数部分

输出：

#1
hex: 3f, dec: 63, oct: 77
#2
3.142
b = 3.142
3.1416
     3.142
3.142     
000003.142
+3.141593
#3
123456qwq   123
#4
 1.23qwq 1.20qwq 1.30

三、换行与不换行

print 函数会自动在输出末尾加上 \n （换行符）

如果需要不换行，只需要写上 end='' 就行了，如下

print(111, end = '')

写成双引号也是可以的

print(111, end = "")
