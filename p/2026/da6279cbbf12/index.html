解决 Live2D 看板娘模型缺失 textures.cache 文件的问题

发表于2026-11-19|更新于2026-11-19|笔记
|总字数:570

解决 Live2D 看板娘模型缺失 textures.cache 文件的问题

省流：建一个空文件，在每个模型的文件夹里都放上就行了。

最近更新了一下 blog 的 live2d-widget 和 live2d_api 。其实主要是 live2d-widget，作者更新了 v1 版本。

它的 README 文件这么写的（自 1.0 版本起）：

相关功能已通过前端实现，因此不再需要专门的 apiPath，所有模型资源都可通过静态方式提供，

只要存在 model_list.json 和模型对应的 textures.cache，即可支持换装等功能。

问题是这个 live2d_api，也就是提供模型的仓库，是一个年代久远的仓库。

按照这个模型仓库的说法、用法和实际文件，直接下载它的仓库，得到的模型都是没有 textures.cache 的。

我其实也不是很懂这些东西的原理，我只知道前面的仓库负责运行，后面的仓库负责提供模型。

然后啥也不管，先跑一个试试看，结果好像没什么问题，按 F12 看一下发现，唯一的问题是会有下面这个报错。

因为这是个 cache 文件（缓存文件？），加上我测试下来并没有什么问题，所以我怀疑不是必要文件。

以前的 live2d-widget 对静态博客的支持很差，每次换页面都会随机变装，而且你改配置文件也没用。

毕竟人家不支持嘛……不过就这样我也用了好几年，你就说能不能用吧？因此这次我也是抱着这个心态的。

不过它每次切换都会跳个报错，虽然没有任何问题，但是实在是看着难受。

解决办法很简单，建一个空的 textures.cache 文本文件，复制到每个模型的目录下就好了。

具体的位置像下面这样，这个是 live2d_api 的说明文档里写的，可以自己去看。

│  index.json
│  model.moc
│  textures.cache       // 皮肤列表缓存，自动生成
│
├─motions
│      idle_01.mtn
│      idle_02.mtn
│      idle_03.mtn
│
└─textures
        default-costume.png
        school-costume.png
        winter-costume.png

然后就搞定了，自己试试看吧。不理解的可以直接去 Github 看我的仓库里 /qwq/cdn/ 里面的文件怎么搞的。
