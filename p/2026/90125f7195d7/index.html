Photoshop 2024 阻止非正版检测弹窗

虽然我可能喜欢支持正版，但是我可不是等着被割的韭菜。（甚至还是日语，太君这边请）

本来用着免费版Photoshop，结果某次使用某种工具的时候，居然被这破软件发现猫腻了

根据可信度未知的方法，如果你不小心使用了某种工具并跳了这个弹窗，那么也许立即重启电脑是一个办法。

如果你像我一样咕咕了好久这个问题，直到现在断网打不开、联网打开自动弹窗并关闭才开始解决问题……

总之我就先把 Adobe 全家桶删了个一干二净（可以使用 Adobe Creative Cloud Cleaner，其他方法我也不会）

接着重新安装 Creative Cloud 和 Photoshop 的免费版，注意虽然全程可以联国内网但不要使用魔法。

然后如果你使用了一款图标很像 🦊 的某种开源工具，那么需要在全局扩展脚本里加入类似下面的内容

const prependRule = [
  "DOMAIN-SUFFIX,adobe.io,REJECT",
  "DOMAIN-SUFFIX,adobestats.io,REJECT",
  "DOMAIN-KEYWORD,adobe,REJECT",
];
function main(config) {
  // 把旧规则合并到新规则后面(也可以用其它合并数组的办法)
  let oldrules = config["rules"];
  config["rules"] = prependRule.concat(oldrules);
  return config;
}

具体怎么让这一串奇怪的文本运作起来，还是请查看 🦊 的官方文档吧

其实只加最后一行就可以，它会把所有和 adobe 有关的网络链接全部掐掉

副作用的就是这么写的话，这只 🦊 就无法随意连接 adobe 相关的网站了，

不过我觉得这也不算什么问题，它都有免费版了，我也不必亲自登门道谢，是吧

题外话：

本期废话有点多，可能是因为这篇文章是我做梦梦见的。

然后其他版本的 PS 我不知道行不行没试过，理论上都是同一个逻辑。
