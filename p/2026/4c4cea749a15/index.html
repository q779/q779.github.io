Hexo 生成美观的永久链接

这里就直接推荐我的方式了，而且不需要安装插件

找到 Hexo 博客文件夹根目录的 _config.yml ，找到以下部分并修改既可

# hash 值是文件名和日期的 SHA1 哈希值（12位16进制数）
permalink: p/:hash/
permalink_defaults:
pretty_urls:
  trailing_index: true # Set to false to remove trailing 'index.html' from permalinks
  trailing_html: true # Set to false to remove trailing '.html' from permalinks

这样生成的文章链接就是 example.com/p/b45445140fa3/ 这样的形式。

这样生成的链接只会在更改文件名或日期时变更，日期就是 date 的参数，默认是文件创建日期。

如果你需要自定义的链接形式，那么请查阅官方文档，或者下面的参考文献。

参考文献：

Hexo 博客删除 .DS_Store 文件
Hexo 博客删除 .DS_Store 文件 直接 cd 到博客根目录，在终端里输入以下指令 find . -name '.DS_Store' -type f -delete 如果怕上面的代码乱删东西，可以用下面这行先看一眼 find . -name '.DS_Store' -type f -print 接着部署就完事了，注意部署之前不要用 Finder 打开相关目录 另外，可以在博客根目录的 _config.yml 里进行以下配置 include: exclude: # 在下面这里添加即可，中括号可以不加 ignore: ["**/.DS_Store"] 这样就不会上传任何 .DS_Store 文件了哦 注意，这个 ignore 和 skip_render 是不一样的， skip_render 配置的是不处理、直接 copy 的那些文件到 public 文件夹； 而 ignore 是直接跳过这些文件，和 exclude 类似， 不过 exclude 只影响 source/，ignore 影响所有文件夹。 参考文献： [1] 配置 | Hexo

在 Hexo 中置顶文章 本文采用 Hexo 默认安装的 hexo-generator-index 进行介绍（版本号 4.0.0） 如果不知道自己有没有安装的话，可以看看 Hexo 根目录下的 package.json 文件里有没有 之前一直用的 Matery 主题，它只需要在 front-matter 写上 top: true 就行了 结果研究 Butterfly 主题和其他主题的时候，才发现这不是通用写法，于是去查了一下文档 hexo-generator-index 的置顶写法应该是像下面这样 --- title: Hello World date: 2000-01-01 00:00:00 sticky: 100 --- 其中 sticky 后面的参数值越大，代表置顶时的优先级越大。 当然，就像 Matery 主题的方法不同，具体还是参考各个主题的官方文档。
