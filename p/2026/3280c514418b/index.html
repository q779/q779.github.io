Hexo 版本更新教程

全局更新 Hexo 的命令行界面（这个就是调用 hexo init 用的那个东东）

npm install hexo-cli -g

如果需要以往的特定版本，可以用下面这个（具体版本可以看 npm 官网 点这里）

npm install hexo-cli@4.3.1 -g

接下来，更新 Hexo 博客的版本，需要先打开位于你的博客文件夹的终端，直接

npm install hexo

不过本人不建议直接更新成最新版，很容易有各种兼容问题

建议更新至特定版本，具体更新到哪个版本，可以看官方文档的更新日志 点这里

npm install hexo@7.3.0

安装完别忘记 hexo clean 一下再生成呀，笨比博主就踩了个坑

需要确认自己的 Hexo 版本是啥，可以用以下命令

hexo -v

另外，更新 node.js 的方法也很简单，这里就简单写一写（笨比博主也不是很会）

# 下面这行可以显示已有的 nodejs 版本
nvm -ls

# 如果没有 nvm, 那就去 nodejs 官网看怎么下载吧

# 下面这行可以显示当前使用的 node 的版本
node -v

# 可以去 nodejs 官网看看当前稳定版是啥，然后去下载叭
# 下面这行可以安装特定版本的 nodejs, <数字> 指的是比如 v22 就是 22
nvm install <数字>

# 卸载已有版本就用下面这个命令
nvm uninstall <数字>
