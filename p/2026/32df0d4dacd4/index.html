一、缺省源

这个缺省源就是输入开头几个字符，然后点回车就能直接出现的模板。

打开方式为 command + shift + p ，输入 Configure User Snippets ，点击 cpp.json 文件。

二、配置文件

MacOS 没有万能头文件，需要自己去 bits/ 目录下新建一个 stdc++.h ，具体方法在本站搜“万能头文件”。

c_cpp_properties.json

{
    "configurations": [
        {
            "name": "Mac",
            "includePath": [
                "${workspaceFolder}/**"
            ],
            "defines": [],
            "macFrameworkPath": [
                "/Library/Developer/CommandLineTools/SDKs/MacOSX.sdk/System/Library/Frameworks"
            ],
            "compilerPath": "/usr/bin/clang",
            "cStandard": "c17",
            "cppStandard": "c++20",
            "intelliSenseMode": "macos-clang-arm64"
        }
    ],
    "version": 4
}

tasks.json

这里 -Wconversion 可以选择性打开，打开可能会导致漫天飞舞的垃圾警告。

比如 string s; ，你用一个 int i 去访问 s[i] ，它就会警告你 i 会被隐式转为 unsigned long 。

{
    "version": "2.0.0",
    "tasks": [
        {
            "type": "cppbuild",
            "label": "C/C++: clang++ 生成活动文件",
            "command": "/usr/bin/clang++",
            // 编译警告指令参考 https://blog.csdn.net/weixin_42102584/article/details/88616467
            "args": [
                "-g", // 便于gdb调试
                "-O2", // O2 优化
                "-Wall", // 一堆警告，参考https://blog.csdn.net/u014044624/article/details/115221092
                "-Wextra",
                "-Wformat", // scanf & printf 传参检测
                "-Wfloat-equal", // 浮点型直接用 == 比较会报警告
                "-Wempty-body", // if,for,while等不小心加分号报警告
                "-Wshadow", // 变量重名警告
                "-Wuninitialized", // 警告未初始化的变量
                "-Wreturn-type", // 非 void 函数无返回值警告
                "-Wparentheses", // 警告可能缺失的大括号，例如if,if,else
                "-Wsizeof-pointer-memaccess", // 警告 memset 中，第三个参数是对指针变量进行的 sizeof
                // "-Wconversion", // 警告可能造成数据范围损失的（自动）类型转换，如 long long 转 int
                "-fsanitize=address", // 用于检测越界访问、释放后使用等内存错误
                "${file}",
                "-std=c++20",
                "-o",
                "${fileDirname}/${fileBasenameNoExtension}"
            ],
            "options": {
                "cwd": "${fileDirname}"
            },
            "problemMatcher": [
                "$gcc"
            ],
            "group": {
                "kind": "build",
                "isDefault": true
            },
            "detail": "编译器: /usr/bin/clang++"
        }
    ]
}
